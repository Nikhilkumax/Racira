# Run doc — racira-nextjs dev server (Racira)

## Reproduce uncommitted artifacts a fresh checkout needs

1. **Env files:** none required. This checkout has no `.env.local` / `.env` and the
   dev server runs without one. If a future feature adds one, COPY it from the main
   checkout `C:\Racira\racira-nextjs` (never symlink — ports may need adapting).
2. **Install dependencies:** `npm install` (project uses npm; lockfile is
   `package-lock.json`). `postinstall` runs the asset-copy patchers automatically
   (`patch-lamejs`, `copy-ffmpeg-core`, `copy-espeak-core`, `copy-ort-wasm`).
3. **Playwright browsers (only for e2e):** `npx playwright install chromium`
   (already present under `%LOCALAPPDATA%\ms-playwright` on this machine).
4. **Static assets the dev server expects under `public/`:** regenerated by the
   `predev` hook (`scripts/copy-ffmpeg-core.cjs`, `copy-espeak-core.cjs`,
   `copy-ort-wasm.cjs`) — running `npm run dev` does this automatically; they are
   no-ops when already up to date.

## Run the server

- Command: `npm run dev` → `next dev -p 3002` (project default port **3002**).
- Detached (Windows, PowerShell — stdout and stderr must go to different files):
  ```powershell
  (Start-Process -FilePath 'npm.cmd' -ArgumentList 'run','dev' `
    -RedirectStandardOutput '<log>.log' -RedirectStandardError '<log>.err' `
    -WindowStyle Hidden -PassThru).Id
  ```
  Note: this launcher call can hang the calling shell even though the server
  starts fine — verify by port/pid, not by the launcher exiting.
- Confirm it is up: `netstat -ano | findstr :3002` shows LISTENING, and
  `curl -s -o NUL -w "%{http_code}" http://localhost:3002/` returns 200.
- Stop: `taskkill /PID <pid> /T /F` (kills the npm→node tree).
- Useful routes: `/` (home), `/cad` (CAD index), `/cad/scale-paper-tool` (thread's tool).
- e2e for the paper tool: `npx playwright test e2e/scale-paper-tool.test.ts`
  (config auto-starts its own dev server on 3002 and reuses a running one).
- SEO-drift guard (pure data test, no browser): `npx playwright test e2e/scale-paper-tool.catalog.test.ts`
  — pins the batch6.ts catalog/series/unit claims to the live arrays.
- Catalog sanity scripts: `node scratch/paper-size-audit.mjs`,
  `node scratch/paper-unit-roundtrip.mjs`.
- Duplicate-name evidence shots (writes `scratch/dupe-shots/*.png`):
  `node scratch/shot-dupes.mjs` (needs the dev server running).
- Typecheck (needs the big heap): `NODE_OPTIONS=--max-old-space-size=6144 npx tsc --noEmit`.
